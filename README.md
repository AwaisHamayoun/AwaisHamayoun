## ⭐ Featured Project — ML Algorithms From Scratch

A complete machine learning library built entirely with NumPy, implementing core ML algorithms without relying on machine learning frameworks.

Built to understand the mathematics and implementation details behind modern machine learning algorithms rather than relying solely on high-level libraries.

**Highlights**
- 13 machine learning algorithms implemented from scratch
- Supervised, unsupervised, and ensemble learning
- Visual explanations using Jupyter notebooks
- Comprehensive testing and modular architecture
